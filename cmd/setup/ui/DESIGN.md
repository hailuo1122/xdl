# XDL 安装器 · 界面方案

一个 Windows 下载器的安装 / 卸载窗口。不是向导，是一块只有一屏的仪表。

窗口：WebView2 客户区 800×520（`cmd/setup/main_windows.go`），页面按这个尺寸设计，所有尺寸挂在 `--u = min(1vw, 1.6vh)` 上等比缩放。

---

## 1. 概念

**「传输台」**：整扇窗是一块冷钢面板。上面是铭牌（XDL + 版本），中间是安装目标和一句说明，下面是一条横贯整幅、像被铣进面板的暗槽——八条传输通道躺在里面。右边是控制舱：一个大数字读数，一枚压在凹槽里的实体按键。

只保留一个记忆点：**这条通道槽**。待命时它慢慢巡检，安装时八条轨道不同步地涨，完成时一起封口。其余部分安静：一种字体系统、两条细线、一个按钮、没有卡片、没有阴影堆叠。

## 2. 色板（6 个命名色）

| 名称 | 值 | 用途 | 说明 |
| --- | --- | --- | --- |
| 冷石 stone | `#E4E6E0` | 机身底色 | 偏冷的灰绿，不是奶油暖白；整页最大面积 |
| 霜白 frost | `#F5F6F2` | 读数面、按键 | 比底色亮一档，不刺眼，不是纯白 |
| 石墨 graphite | `#1A1F1D` | 主文字、主键、铭牌 | 带绿味的近黑，不是 `#000` |
| 钢灰 slate | `#5B645F` | 次要文字、刻度 | 在霜白上 5.6:1，正文可读 |
| 青绿 jade | `#24705A` / `#5FC3A6` | 链路接通、进度 | 只出现在「有数据在动」的地方；暗槽里用亮一档的 `#5FC3A6` |
| 铜 brass | `#9A5B2C` | 品牌第二枚箭头、故障刻度、错误读数 | 全页占比不到 2%，不做主按钮 |

派生：`--deck #121716`（槽底）、`--deck-dim #98A29B`（暗槽里的次要字，6.4:1）、`--hairline rgba(26,31,29,.16)`。

**为什么不像雷区**

- 不是「暖奶油 + 衬线 + 陶土橙」：底色冷，标题无衬线，铜只做 3px 箭头和故障刻度，从不做 CTA。
- 不是「纯黑 + 唯一荧光」：机身浅色，暗槽只占下半部；青绿是功能色（进度/接通），不是氛围霓虹。
- 不是「圆角卡片 + 同款软阴影」：全页零卡片，圆角只有按键的 2px；唯一的投影属于那枚实体键。
- 背景有层次但不脏：一层从左上来的霜白径向光、一层 6% 胶片颗粒、上/左两条量具刻度边。没有装饰渐变。

## 3. 字体

- **IBM Plex Sans**（400 / 500 / 600，latin 子集，自托管 woff2，内联进单文件）
- **IBM Plex Mono**（400 / 500，路径、版本、百分比、连接数）

同一套 superfamily。Plex 本来是为界面与技术文档画的，方 terminals 和略窄的字面读起来像仪表。Sans 说话，Mono 读数。

中文：`DengXian / 等线 → Microsoft YaHei UI → PingFang SC`。**不内嵌 CJK 字体**：完整中文字库 8–12MB，塞进安装器不划算；等线在 Windows 10/11 自带，比雅黑更轻、更接近仪表而不是后台。要完全锁定品牌字，可用 `pyftsubset` 把 IBM Plex Sans SC 裁到实际用到的几百个字再内联。

字号角色（800×520 下）：

- 品牌 `XDL`：600 / 75px / `-0.052em`。全页唯一的重字重。
- 状态标题：400 / 23px。刻意不加粗，让品牌是唯一主角。
- 说明：14.5px / 1.7 / 最大 560px（约 35 字一行）。
- 读数：Plex Mono，`tabular-nums`。

理由：一条完整的横向构图，左轴严格对齐；暗槽横贯整幅，是「被加工出来的一条槽」而不是一张卡片；控制舱在右侧和页脚「关闭」共用同一条右轴，品牌、版本、按键、关闭形成一列纵向刻度。主操作不在页脚孤零零地待着，而是长在仪表上。

## 5. 动效

| 时机 | 动作 | 参数 |
| --- | --- | --- |
| 入场 | 暗槽先升起 → 八条凹槽从左往右「画」出来 → 品牌从遮罩里顶出、两枚箭头描边 → 文案 → 按键弹入 | 0–0.9s，`cubic-bezier(.16,1,.3,1)`，凹槽每条 42ms 错开 |
| 待命 | 一道 120px 的微光沿通道巡检，八条错开 110ms，6.4s 一轮 | 透明度峰值 .28 |
| 安装中 | 每条通道宽度 540ms 缓动，错开 16ms；推进端 1px 亮线 + 8px 辉光；整排每 3.6s 扫过一层 10% 的光 | 状态文字用 4px 模糊 + 位移换字 |
| 按键 | hover 抬 1px、阴影拉开；按下压 1px、内阴影；底部 2px 青绿线 = 总进度 | 160–200ms |
| 完成 | 八条分段缝一起「封口」（每条错开 38ms）→ 槽底 2px 接缝从左画到右 → 数字滚到 100 → 铜箭头向墨色箭头轻磕 2.6px 再弹回 | 总 0.8s，无彩带、无烟花 |
| 错误 | 通道去色、压暗；一条 2px 铜线钉在断点，读数转铜 | 400ms 淡入 |

`prefers-reduced-motion: reduce`：CSS 全局把动画/过渡压到 0.001ms，巡检与扫光 `display:none`；React 侧 `useReducedMotion()` 为 true 时所有 `initial/animate` 关闭，错开延迟归零。

## 6. 状态与文案

| 状态 | 标题 | 说明 | 主键 | 次键 |
| --- | --- | --- | --- | --- |
| ready / 首次安装 | 安装到这台电脑 | 写入当前用户目录，不需要管理员。已有的下载和历史都会保留。 | 安装 | 关闭 |
| ready / 已安装 | 覆盖安装 | 已经装了 {ver}，继续会覆盖程序文件。下载记录保留。 | 覆盖安装 | 关闭 |
| ready / 卸载 | 卸载 XDL | 会删掉程序、浏览器组件和开始菜单入口。下载记录仍然保留。 | 卸载 | 关闭 |
| working | 正在安装 / 正在卸载 | 阶段文案（progress.status），下一行 mono 细节 | 安装中（禁用） | 关闭（禁用） |
| done / 安装 | 装好了 | 开始菜单里已经有了，浏览器接管也开好了。 | 打开 XDL | 关闭 |
| done / 卸载 | 卸载完成 | 程序和浏览器组件已经移除。下载记录还在。 | 关闭 | — |
| error | 没有装完 / 没有卸干净 | 中断 + 具体原因（mono） | 再试一次 | 关闭 |
| 缺文件 | 安装包不完整 | 这个安装程序里没有附带 XDL。请重新下载完整安装包。 | 缺少文件（禁用） | 关闭 |

卸载模式不显示安装路径，换成「将保留 / 下载记录」；安装中路径变暗、不可点；卸载中整个路径区不出现。

## 7. 和 Go 的进度约定

`Progress.ratio` 在 Go 侧是「阶段进度」：`files` 阶段是真实字节比，`host` / `shortcuts` / `registry` 都给 `1`。页面在 `globalRatio()` 里折算：

```
files 0..1 → 0..0.86
host       → 0.90
shortcuts  → 0.94
registry   → 0.97
resolve    → 1（完成态）
```

卸载阶段的 0.2 / 0.55 / 0.8 / 1 本身就是全局进度，原样使用。这样百分比不会在「刚写完文件」时就跳到 100。

## 8. 怎么避开「AI 味」

- 没有卡片网格、没有 16px 圆角、没有同款阴影。全页只有一个阴影，属于那枚真的按键。
- 没有 01 / 02 / 03 步骤。唯一的「序列」是通道本身，它是数据不是步骤。
- 没有全大写小标签、没有 `A · B · C` 中点串、没有 `WORD — fragment`、按钮后面没有箭头。
- 不用 Inter / Roboto / 系统默认。品牌 Plex 600 撑到 75px，标题反而用 400，靠字号而不是字重建立层级。
- 没有大片死黑留白或孤立按钮：暗槽满幅，主键长在槽里，页脚只留一个安静的「关闭」。
- 进度不是一根空条：待命时是八条会呼吸的凹槽，运行时是八条不同步的流，完成时封成八块玉石。

## 9. 已知取舍

- 800×520 是硬约束（要兼容 1366×768@125% 的笔记本）。品牌只能到 75px，仪表的呼吸空间靠 `--u` 等比缩放；窗口再大当然更舒展。
- 八条通道在静态截图里可能被读成均衡器；「8 条连接」这行字负责把它拉回下载器。
- 完成态的静态画面克制到几乎不庆祝，情绪主要交给那 0.8 秒的封口动作。
- 等线只在 Windows 上有，macOS / Linux 会落到 PingFang / 思源，观感略有差异。
